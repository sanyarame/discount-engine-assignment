# Opptra Discount Engine

An enhanced discount engine with item-level and cart-level discounts, AI-powered discount rule creation, and PDF cart import.

## Live Deployment
https://discount-engine-assignment-in1u-oulvowfwi-sanya-31b0.vercel.app

## Run Locally

1. Clone the repository and install dependencies:
   ```bash
   git clone https://github.com/sanyarame/discount-engine-assignment.git
   cd discount-engine-assignment
   npm install
   ```

2. Create a `.env` file in the project root and add your Gemini API key:
   ```env
   GEMINI_API_KEY=your_api_key_here
   ```

3. Start the frontend and backend in separate terminals:
   ```bash
   npm run dev
   npm run server
   ```
